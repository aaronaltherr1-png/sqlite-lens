# Contributing to SQLiteLens

Thank you for your interest in contributing to SQLiteLens! We welcome contributions from developers of all skill levels.

## How to Contribute

### 1. Reporting Bugs
- Search existing issues before creating a new one.
- Provide a clear, descriptive title and steps to reproduce.
- If possible, include the SQLite schema or sample query that triggered the issue.

### 2. Suggesting Features
- Open an issue with the tag `enhancement`.
- Describe why this feature would be valuable for developers inspecting SQLite databases.

### 3. Submitting Pull Requests
1. Fork the repository.
2. Create your feature branch (`git checkout -b feature/amazing-feature`).
3. Commit your changes (`git commit -m 'Add amazing feature'`).
4. Push to the branch (`git push origin feature/amazing-feature`).
5. Open a Pull Request.

## Local Development Guidelines
- Keep the codebase lightweight: Avoid adding unnecessary heavy npm dependencies.
- Maintain client-side privacy: No remote telemetry or external database transmission.
- Test your changes using `npm run build` before submitting a PR.
